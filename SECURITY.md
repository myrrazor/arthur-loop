# Security Policy

Arthur Loop is a local CLI and optional macOS companion. Treat workspace files,
adapter credentials, and logs as sensitive.

## Supported Versions

Security fixes target the current `main` branch and the latest release tag.

## Reporting A Vulnerability

Use GitHub private vulnerability reporting:
https://github.com/myrrazor/arthur-loop/security/advisories/new

Do not post secrets, API keys, tokens, or private workspace files in public
issues.

If private reporting is unavailable, open a public issue with a minimal title
and no sensitive details, then ask a maintainer for a private channel.
