First loop

A cockpit first. Auto-follow only on this branch.

Old live copy said “four commands to a running loop” and implied MCP after a curl-main install. That is not true of public main.

On public main / v0.1.0

mkdir ~/my-loop && cd ~/my-loop
arthur init --yes --main-agent none --advisor manual --executor manual --tracker none --no-governor
arthur queue create --job-id BQ-MY_APP-001 --project-id MY_APP \
  --target-chat-title "MY_APP planning" --target-chat-url manual \
  --expected-marker HELLO_LOOP --idempotency-key my-app-001
arthur status
arthur web

You still claim, submit, capture, and poll yourself. arthur init --demo seeds a busy dashboard. That is a demo, not a working agent loop in minutes.

On this branch

pipx install 'git+https://github.com/myrrazor/arthur-loop.git@cursor/atlas-product-gap-ab6b'
mkdir ~/my-loop && cd ~/my-loop
arthur init --yes --main-agent grok --preset solo
arthur loop create --project-id MY_APP --advisor grok --executor grok
arthur follow --once

Grok transport is grok --always-approve -p PROMPT. Folder trust: grok --trust (install runs it unless --no-trust-folder). If the tracker is Atlas, arthur loop create writes tracker.project_map (MY_APP → MY). Do not walk an empty map.

Human gates remain: open decisions, ChatGPT-browser / manual inboxes, implementation-gate NO-GO.
