Two install stories. Do not mix them.

The last public tag is v0.1.0. There is no v0.2.0 release. arthur --version prints that package version. Live marketing that says otherwise is wrong.

Public main (the three homepage install commands) is a file cockpit: init, queue, capture, gate, status, arthur web. It does not ship arthur follow, a stdio MCP server, or Atlas walk.
This branch (cursor/atlas-product-gap-ab6b) adds skills, MCP, arthur follow, and Atlas next/walk. Install it on purpose. Do not tell someone the curl-main path produced those commands.
