Documentation

One install. Then /arthur-loop.

Arthur Loop keeps long-running AI coding work on a written contract: a durable queue, saved artifacts, approval gates, and project-scoped human decisions. State is markdown and JSONL in a directory you own.

The path. Install the CLI → arthur init writes skills and MCP → restart the client → assign planner, implementer, reviewer, and QA → arthur or Run next invokes the next role.
