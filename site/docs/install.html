Install

Pick the tree you actually want.

Python 3.9+ is the only core requirement. Confirm with arthur --version — it prints arthur 0.1.0 until the next tag. That is the last release number, not proof you installed follow/MCP.

Public main / last tag v0.1.0 — file cockpit

These three commands track default git HEAD (usually main). They install queue, capture, gate, status, and arthur web. They do not install arthur follow, MCP, or Atlas walk.

pipx install git+https://github.com/myrrazor/arthur-loop.git

uv tool install git+https://github.com/myrrazor/arthur-loop.git

curl -fsSL https://raw.githubusercontent.com/myrrazor/arthur-loop/main/install.sh | sh

Then: mkdir ~/my-loop && cd ~/my-loop && arthur init. That is a durable cockpit, not a working auto-follow in minutes.

This unreleased branch — follow, MCP, Atlas walk

pipx install 'git+https://github.com/myrrazor/arthur-loop.git@cursor/atlas-product-gap-ab6b'

# or
uv tool install 'git+https://github.com/myrrazor/arthur-loop.git@cursor/atlas-product-gap-ab6b'

# or from a checkout of this branch
./install.sh

Optional curl of this installer, still cloning the named ref:

curl -fsSL https://raw.githubusercontent.com/myrrazor/arthur-loop/cursor/atlas-product-gap-ab6b/install.sh \
  | ARTHUR_LOOP_REF=cursor/atlas-product-gap-ab6b sh

arthur --version still prints arthur 0.1.0 (setuptools metadata). The extra commands are how you tell the trees apart: arthur follow --help, arthur mcp --help, arthur tracker walk --help.

Windows

https://raw.githubusercontent.com/myrrazor/arthur-loop/main/install.ps1 is a 404 on public main. Do not copy that URL from old live copy. This branch ships an experimental install.ps1 next to install.sh. From a checkout of this branch: ./install.ps1. WSL remains the well-tested path.

Canonical site

Production is https://arthurloop.com/. arthur-loop.vercel.app is not a working host (404). This repo’s site files now use arthurloop.com as canonical.
