CLI

The CLI is the product. MCP is this branch only.

Public main has no arthur mcp extra and no pip install 'arthur-loop[mcp]' extra. That live-docs sentence was a fiction. On this branch, MCP is part of the package: arthur mcp serve.

Everyday commands (both trees)

arthur --version          # arthur 0.1.0 until the next tag
arthur status
arthur tick --dry-run
arthur web
arthur watch
arthur queue create|claim|submit|poll-result|complete|fail
arthur capture
arthur gate implementation --project-id X
arthur decision list

An open human decision pauses that project. On this branch, pause refuses claim, submit, poll-result, complete, and fail (exit 2). Cancel and recover still work.

This branch only

arthur integrations install --targets claude,codex,cursor,grok
arthur follow --once
arthur mcp serve
arthur mcp serve --tool-name-style portable
arthur loop create --project-id MY_APP
arthur tracker next --json
arthur tracker walk --dry-run

There are not “six MCP tools.” This branch ships status, tick, queue, capture, gate, decision, loop, board, tracker, and follow tools (dotted names plus Grok-safe arthur_status / arthur_follow_run).
