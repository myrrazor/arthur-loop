CLI

The CLI is the product. MCP is the same product over stdio.

There is no extra pip install 'arthur-loop[mcp]'. After a normal install, arthur mcp serve is part of the package. Init registers it for you.

Everyday commands

arthur --version
arthur init
arthur status
arthur tick --dry-run
arthur web
arthur watch
arthur loop create --project-id MY_APP --advisor grok --executor claude-code
arthur follow --once
arthur integrations install --targets claude,codex,cursor,grok
arthur gate implementation --project-id MY_APP
arthur decision list

An open human decision pauses that project: claim, submit, poll-result, complete, and fail exit 2. Cancel and recover still work.

MCP tools

Dotted names are canonical. Grok registrations use portable names (arthur_status, arthur_loop_create, arthur_follow_run).

Read: arthur.status, arthur.tick, arthur.queue.show, arthur.queue.due, arthur.gate.implementation, arthur.decision.list, arthur.loop.list, arthur.board, arthur.tracker.next, arthur.tracker.queue.

Gated write: arthur.queue.create, arthur.queue.claim, arthur.queue.submit, arthur.queue.poll_result, arthur.queue.recover, arthur.capture, arthur.decision.open, arthur.decision.answer, arthur.loop.create, arthur.board.open_jobs, arthur.tracker.walk, arthur.follow.run.

The /arthur-loop prompt interviews for roles, calls arthur.loop.create, then arthur.follow.run.

arthur mcp serve
arthur mcp serve --tool-name-style portable
arthur mcp tools --json
arthur mcp call arthur.status

Follow

arthur follow claims, invokes the CLI adapter, captures, gates, and enqueues the next hop when the adapter has a headless transport. It will not skip a human decision or invent plan approval. ChatGPT-browser and manual adapters write an inbox file and stop.

Repo detail: docs/mcp.md, docs/follow.md.
