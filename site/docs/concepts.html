Concepts

Files, not a hosted loop.

A queue is an append-only JSONL state machine. An artifact is saved advisor/executor text before anything acts on it. A gate is GO/NO-GO from those files. A human decision pauses one project. A tick classifies what should happen next without spending tokens.

Those objects exist on public main / v0.1.0. arthur follow, MCP, and Atlas walk do not. Pause on this branch also blocks poll, complete, and fail.
