FAQ

Before you wire it in.

What do I get from the three homepage commands?

Public main / last tag v0.1.0: a Python CLI for durable queues, artifacts, approval gates, human decisions, status, and a local web console. Not MCP. Not arthur follow. Not Atlas walk.

Is there a v0.2.0 release?

No. Some live pages said “latest release v0.2.0.” There is no such tag. arthur --version prints arthur 0.1.0. Unreleased work lives on cursor/atlas-product-gap-ab6b.

Is it free?

Yes. MIT licensed, no paid tier.

Where is my data? Does it phone home?

Markdown and JSONL in the instance directory you choose. The core does not phone home or require an API key.

Which platforms work?

The Python CLI is exercised on macOS and Linux. Windows is experimental; public main has no install.ps1 (that URL 404s). This branch ships an experimental install.ps1 in the repo only. ArthurBar is macOS 14+.

Why did arthur-loop.vercel.app 404?

That hostname is not the production site. Canonical URLs in this repo now point at https://arthurloop.com/.

How do I update or uninstall?

Repeat pipx/uv/curl (add --force for pipx/uv). Uninstall with pipx uninstall arthur-loop or delete ~/.arthur-loop and ~/.local/bin/arthur.
