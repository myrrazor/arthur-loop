01 / HOW IT WORKS

Three steps. Then the agent drives.

You do not wire the queue by hand unless you want to. Install the CLI, let init seed your agents, then describe the loop from inside the agent you already use.

  1. 01 — INSTALL

    One command, isolated arthur

    pipx, uv, or the shell installer. Python 3.9 or newer is the only core requirement. No hosted account.

  2. 02 — INIT

    arthur init writes the skill

    It detects Claude Code, Codex, Cursor, and Grok Build, copies adapter packs, writes /arthur-loop where those clients load skills, and registers arthur mcp serve. Restart the client so MCP connects.

  3. 03 — /ARTHUR-LOOP

    Specify the loop in the agent

    Run /arthur-loop. Assign planner, implementer, reviewer, and QA. Arthur formulates the default sequence. Then arthur or console Run next calls the next agent. Same wizard: arthur web. Ready Atlas Tasker tickets walk in with arthur tracker walk.

02 / THE SEAMS

The handoffs are the product.

Arthur Loop does not choose your models. It keeps the work between them inspectable, recoverable, and gated.

  • Crash without amnesia

    Append-only queue ledgers and saved artifacts replay to the last recorded step. Recovery frees the dead manager's lease.

  • Gate untrusted output

    Advisor and executor text is stored before use. Only the final fenced control block is parsed. Unexpected values are quarantined and open a human decision.

  • Block one project

    A human question pauses the project that asked it. Other projects keep moving through the same loop.

  • See the same state twice

    arthur status, JSON output, MCP tools, and the localhost console read the same files. No database sits in the middle.

  • Bring your stack

    Shipped packs for Codex, Claude Code, and Grok Build. Cursor gets skills and MCP. Atlas Tasker can walk ready tickets. Manual and ChatGPT-browser advisors remain first-class.

03 / CONSOLE

A status map, not a graph composer.

arthur web is the browser twin of arthur status. Assign roles, run the next hop, answer decisions, recover stale jobs, create a loop. Agents own the hop itself.

04 / MENU BAR

The loop, from the macOS menu bar.

ArthurBar is a native menu extra for macOS 14+. It lives in the menu bar — the strip at the top of the screen — so you can manage agent loops without a terminal or a browser tab in the way.

  • Always in reach

    An ∞ icon sits with the other menu extras, next to Control Center and the clock. One click opens workers, the queue, projects, and the browser lock — the same snapshot as arthur status.

  • It taps you when you are needed

    The icon badges with a count of open human decisions and stale jobs. Hover the item for the loop state. Want a banner as well? Run arthur watch for Notification Center alerts on decisions, quota blocks, due work, and stale jobs.

  • Quota for the agents you run

    The popover's quota bar is the loop's governor: percent left, reset time, GREEN / YELLOW / RED. Point it at CodexBar (Codex, Claude, and the other subscriptions CodexBar already reads) or at a command or file. At your reserve line the loop checkpoints instead of burning the last 5%.

05 / INSTALL

One tool. Three paths.

Each method installs an isolated arthur command from current main. Then arthur init is the whole setup.

pipx
› pipx install git+https://github.com/myrrazor/arthur-loop.git
uv
› uv tool install git+https://github.com/myrrazor/arthur-loop.git
curl
› curl -fsSL https://raw.githubusercontent.com/myrrazor/arthur-loop/main/install.sh | sh

Then: mkdir ~/my-loop && cd ~/my-loop && arthur init. Restart your coding agent, run /arthur-loop, and say how you want the loop set up. Impatient? arthur init --demo && arthur web opens a seeded console. arthur --version still prints arthur 0.1.0 until the next tag.

06 / FAQ

Before you wire it in.

What do I get after one install?

An isolated arthur command. arthur init detects Claude Code, Codex, Cursor, and Grok Build, writes the arthur-loop skill and slash command where those clients load them, and registers a local MCP server. In the agent you run /arthur-loop to assign planner, implementer, reviewer, and QA. You also get a durable queue, artifact store, approval gates, human decisions, arthur status, and a localhost web console.

Is Arthur Loop free?

Yes. Arthur Loop is MIT licensed and has no paid tier.

Where is my data stored? Does it phone home?

Queues, artifacts, decisions, sessions, and quota snapshots stay as markdown and JSONL inside the instance directory you choose. The core does not phone home or require an API key. Adapters only invoke tools you configure.

How do I set up the loop in my agent?

Install Arthur Loop, run arthur init in an empty directory, restart the coding agent so MCP connects, then run /arthur-loop. The skill interviews you for project, roles, and tracker, creates the loop, and arthur run invokes the next assigned agent.

Which platforms are supported?

The Python CLI is exercised on macOS and Linux with Python 3.9 or newer. Windows is experimental. ArthurBar requires macOS 14 or newer.

Can I watch the loop from the Mac menu bar?

Yes. ArthurBar is a native macOS 14+ menu extra. An infinity icon sits in the menu bar and badges when a human decision or a stale job needs you. The popover shows workers, the queue, projects, remaining quota for the agents you configured, and the browser lock. It reads arthur status --json and does not change loop state. Build it from menubar/ArthurBar. Pair with arthur watch if you also want Notification Center banners.

How do I update or uninstall it?

Repeat the pipx, uv, or curl install command to update (add --force for pipx or uv). Uninstall with pipx uninstall arthur-loop or uv tool uninstall arthur-loop. Curl installs can be removed by deleting ~/.arthur-loop and ~/.local/bin/arthur.

How do I get support?

Open a GitHub issue for bugs and questions. There is no email support inbox on this site.
