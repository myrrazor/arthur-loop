v0.1.1 — 2026-10-02

arthur init writes skills and MCP for Claude Code, Codex, Cursor, and Grok Build. Stdio MCP server, /arthur-loop, and arthur loop create (CLI, web + Loop wizard, MCP). Assignable roles (planner, implementer, reviewer, QA); bare arthur, arthur run, and arthur follow invoke the next assigned agent, with the same Roles / Run next controls in the console. Atlas next/walk. Queue is a refusing state machine with file locks. Stability fixes: web Run next no longer returns 500 on lock contention, a hop’s expected marker is in its prompt, agent invoke waits up to 45 minutes (configurable), and two followers cannot run the same hop. ArthurBar is still a separate macOS install. arthur --version prints 0.1.1.

Known edges: do not run arthur follow unattended against untrusted input yet. Remaining path and queue-validation gaps are listed in the release notes and slated for v0.1.2. Windows is experimental.

v0.1.0 — 2026-07-16

File-first queues, artifact capture, approval gates, human decisions, quota-aware scheduling, adapter packs, arthur init, local web console, arthur watch, optional ArthurBar.
